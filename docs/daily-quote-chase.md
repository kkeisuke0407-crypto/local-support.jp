# 日次チェック：見積が取れていない案件を止めない

毎朝1回。目的は **「打診したまま放置されている案件をゼロにする」** こと。
コラム執筆の `/daily` とは別物。こちらは受注オペ専用。

## 手順

### 1. 受信を確認する

```
Gmail検索: newer_than:1d -in:sent -from:google.com -from:rakkoserver
Gmail検索: from:contact@local-support.jp newer_than:2d      ← 新規CVとヒアリング回答
```

新規案件があれば `docs/sheet-tab1-cases.csv` に追加してから先へ進む。

### 2. 全案件を「回答が取れているか」で仕分ける

`docs/sheet-tab2-quotes.csv` を案件IDごとに集計し、
**紹介可の件数** を数える。ステータスが `紹介可(...)` で始まる行が対象。

| 紹介可の件数 | 判定 | やること |
|---|---|---|
| 0件 | 🔴 **危険** | 督促と打診先の追加を**同日中**に行う |
| 1〜2件 | 🟡 注意 | 打診先を追加する。比較には最低3件ほしい |
| 3件以上 | 🟢 | 比較ページの用意へ進む（最大5社） |

### 3. 🔴 の案件に対して打つ手（両方やる）

**(a) 督促**

`docs/juchu-operation-sop.md` §7.8 のタイミングに従う。

- 期限の指定がない案件 → 打診から中5営業日
- 依頼者が期限を明示している案件 → 打診から2営業日
- **一度督促して無反応の相手はそれ以上追わない**

督促本文に必ず入れる3点。

1. 期限がある場合はその理由（事実のみ。推測を書かない）
2. 「対応可否」と「初回連絡がいつ頃可能か」の2点だけでよいこと
3. **対応が難しい場合もひと言もらえれば他社を当たること**

**(b) 打診先を増やす**

督促だけでは増えない。同日に新しい候補を足すこと。

- 既存プールの `未依頼` 行から先に消化する
- 足りなければ WebSearch で候補を探す。検索軸は
  「サービス名＋都道府県」「サービス名＋必要な資格・登録」「業界団体の会員名簿」
- **辞退の理由をそのまま検索条件に変える。** これが一番効く
  - 例：ELV-2026-0828-001 は3社が「高山市まで遠い」で辞退
    → 名古屋・岐阜市の会社を足しても同じ結果になる。
      飛騨地域の地元業者／全国網を持つ昇降機専業へ切り替えた
- 追加した業者は必ず `sheet-tab2-quotes.csv` に行を足す（15列を検算）

### 4. 不達を放置しない

ステータス `不達` の行は打診数にカウントされているのに1件も届いていない。
公式フォームか正しいアドレスを確認して再送するか、候補から外して同数を補充する。

### 5. 記録して push

- `docs/sheet-tab1-cases.csv`（17列）/ `docs/sheet-tab2-quotes.csv`（15列）を更新
- 列数を検算し、キリル文字・ハングルの混入を確認（`[Ѐ-ӿ가-힯]`）
- `claude/localsupport-handoff-0730-15igwy` へ commit & push。**mainへのマージはしない**

## やってはいけないこと

- **見積・打診の段階で紹介料の話を出す**（SOP §7.6・2026-09-07 決定）
- **運営が技術的な見立てや提案を推測で書く**（SOP §3.3）
- **依頼者への再ヒアリング**（SOP §3.5.5）。業者選定に必要な情報の確認は可
- **依頼者の連絡先・所在地を選定前に業者へ渡す**
- **2営業日での督促**（依頼者側に期限がある案件を除く）
- 督促を2回以上送る
