# コンテンツSEO ロングテール KW バックログ

施設管理B2B特化ロングテール記事の制作ロードマップ。**高購買意図 × 低競合 × 自社サービスとの直結**を優先順位の3軸とする。

## 運用ルーティン

1. **週1〜2本** のペースで上位から消化
2. 1本あたり **5,000〜6,000字級** / Article + FAQPage 構造化データ必須
3. 既存記事への内部リンクを **3本以上** 必ず張る
4. `data/columns.ts` への登録と該当サービスの `relatedColumns` への追加までで1セット
5. 公開後 **2週間でGSC流入確認**、伸びてる記事は強化、伸びてない記事は内部リンク追加 or タイトル修正

## 📊 公開後のレビュー指標（公開2週間後）

各記事は以下4指標を `seo-scoring-template.csv` に転記する：

1. **GSC表示回数**：100超 → 一定の検索意図ヒット
2. **GSCクリック数**：5超 → 上位5位圏入りシグナル
3. **平均掲載順位**：30位以内 → KW再評価で上位化施策投入
4. **滞在時間（Clarity）**：90秒超 → コンテンツが読まれている

3指標で合格ならカテゴリ強化、不合格なら内部リンク追加 or リライト。
