# 害虫駆除リスティング配信プラン（福岡・日額500円テスト）v1.0

作成: 2026-06-29 / 対象: Google 検索広告（リスティング）/ 予算: ¥500/日（月 約¥15,200上限）

> 目的: 実CVが出た害虫×福岡に、低予算で検索広告を当てて「有料検索でCVが取れるか」をテストする。
> スケール施策ではなく**1点集中の検証**。判断はCTRとフォーム送信（/thanks/到達）で行う。

---

## 0. 配信前チェックリスト（この順でやる）

1. **コンバージョン計測を先に用意**（後述の §6）。計測なしで配信開始しない
2. Google Ads アカウント作成 / 支払い設定
3. キャンペーン作成（§1の設定どおり）
4. 広告グループ1つ＋キーワード（§2）＋除外KW（§3）
5. レスポンシブ検索広告1本＋アセット（§4・§5）
6. 最終URL・自動タグ（gclid）ON
7. 配信開始 → 3〜4日後に初回チェック、以後 週1（§7の判断ルール）

## 6. コンバージョン計測（配信前に必須）

サイトは GA4 導入済み（測定ID: `G-KS0PVE3PY5`、Consent Mode v2）。フォーム送信は `/api/contact` → `/thanks/?source=contact` へ遷移する。**/thanks/ 到達＝コンバージョン**。

### 推奨: GA4 のキーイベントを Google Ads にインポート（コード改修ゼロ）
1. GA4 管理 → 「イベント」または「キーイベント」で、`/thanks/` 到達を表すイベントを用意
   - 簡易: `page_view` のうち `page_location` に `/thanks/` を含むものを対象にカスタムイベントを作成 →「キーイベント」としてマーク
2. Google Ads と GA4 を**リンク**（Ads: 管理→リンク→Google アナリティクス(GA4)）
3. Ads「目標→コンバージョン→新規→インポート→GA4」で上記キーイベントを取り込む
4. 計測が「有効」になってから配信開始

### 代替: Google Ads タグを直接設置（より正確・リアルタイム）
- `AW-xxxxxxxxx` を全ページに、コンバージョンイベントを `/thanks/` で発火
- BaseLayout に gtag があるため追加実装は容易。精度を上げたくなったらこちらへ移行
- ※実装を希望する場合はリポジトリ側で対応可能

### 補助コンバージョン（任意）
- `/audit/`（60秒5問診断）の完了も「補助的なCV」として計測すると、フォーム送信が0でも改善の手がかりになる

## 7. 判断ルール（いつ・何で評価するか）

評価期間: **配信開始から2〜4週間**（月¥15,200で概ね30〜60クリック想定）。

| 指標 | 見方 |
|---|---|
| CTR | 2〜3%以上なら広告とKWの一致は良好。1%未満は見出し/KWを見直し |
| 平均CPC | ¥300上限に張り付くなら、より長いB2Bクエリへ寄せる |
| フォーム送信（CV） | 1件でも出れば「有料検索でCVが取れる」証明。CPA（CV単価）を記録 |
| 検索語句 | 毎週レビュー。良KWは完全一致へ昇格、無駄クエリは除外へ追加 |

**アクション基準**
- CTR良 × CV 0（クリック累計100超）→ LP/オファーの見直し（フォーム位置・文言）
- CV発生 → そのKW・地域を維持し、勝ちKWだけ上限CPCを微増
- 全く伸びない（CTR低・CV0）が4週続く → 一旦停止し、SEO（クラスタ）にリソースを戻す

> 大原則: これは検証。¥500/日で「スケール」はしない。CVの有無と単価を見て、増額（例 ¥1,000/日・大阪追加）の判断材料にする。

## 8. 次フェーズの分岐（テスト結果しだい）

- **CV出た** → 予算を¥1,000/日へ。福岡で勝ちKWを厚く → 次に大阪を同型で追加
- **CV出ない** → 広告は一旦停止。SEOクラスタ強化（勝ち筋判定後にフェーズ2の被リンク）へ集中
- いずれにせよ、**地域は実績が出た所から1つずつ**横展開（SEOと同じ原則）
