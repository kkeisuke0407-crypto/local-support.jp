# 受注オペレーション標準手順（SOP）

見積依頼の受信から成約・クローズまでの**全体フローを1本に固定化**した手順書。
ユーザー・CODEX・Claude の誰が対応しても同じ手順・同じ文面で回せる状態を正とする。

> このSOPが受注オペの**唯一の正**。`operational-routine.md` は日次/週次の運営全体、`tools/quote-url/README.md` は比較ページ生成ツールの詳細、`leads-log.md` は案件の記録先。矛盾があれば本SOPを優先。

---

## 0. 全体フロー（10ステップ）

```
① 受信      : フォーム → /api/quote → contact@local-support.jp に通知メール
② 起票      : leads-log.md（正本はスプシ）に案件を1行起票。案件ID採番
③ 要件確認  : 不足があれば /hearing/ ページ or メールで追加ヒアリング
④ 業者選定  : 該当サービス×エリアの登録業者を2〜3社選ぶ（§4）
⑤ 打診      : 各業者へ「概算見積」を依頼（テンプレA）
⑥ 見積回収  : 概算 or「要現地調査」を回収。台帳更新
⑦ 比較ページ: tools/quote-url で /quote-result/ URLを生成（§比較ページ）
⑧ 提示      : 依頼者へ比較ページURLをメール（テンプレC）
⑨ 選定      : 依頼者がページで業者選択 → /api/select-vendor が contact@ に通知
⑩ 連絡先共有: 選定業者へ依頼者連絡先を共有（テンプレD/現地調査ならテンプレB）→ 成約 or 失注でクローズ
```

**原則**：業者の実名・連絡先は⑧の比較ページでは出さない（A社/B社等）。⑩の選定確定後に運営が共有する＝中抜き防止＝紹介手数料を守る。

---

## 1. ステータス定義（台帳・スプシ共通）

`起票` → `業者打診準備` → `業者打診中` → `見積回収中` → `依頼者へ提示` → `依頼者選定済` → `連絡先共有済` → `成約` / `失注` / `保留`

業者見積タブの `見積ステータス`：`未依頼` / `依頼済` / `見積受領` / `要現地調査` / `辞退` / `不通` / `採用` / `見送り`

---

## 2. 案件ID採番

`{サービス略号}-YYYY-MMDD-NNN`
- 略号：害虫=PCO / 受水槽=WTK / アスベスト=ASB / ダクト=DUCT / 消防=FIRE / グリストラップ=GST など
- 例：`PCO-2026-0619-001`

---

## 3. 担当分担と衝突防止

- ユーザーとCODEXのどちらも業者へ見積依頼できる運用。**送信前に必ずスプシ `業者見積`タブの `依頼担当` に自分の名前を記入し `見積ステータス` を `依頼済` に更新**（先に確保＝二重送信防止）
- `依頼担当=未割当` かつ `未依頼` の行だけが「未着手」
- 記録先の正＝Googleスプレッドシート（2タブ）。`leads-log.md` は経緯メモ

---

## 4. 業者選定の基準（④）

- **登録の確認が必須**：サービスに応じた登録業者を選ぶ（例：受水槽=建築物飲料水貯水槽清掃業／害虫=建築物ねずみ昆虫等防除業。都道府県知事登録）
- エリア：依頼者の都道府県の登録業者。近隣府県からの出張対応も可
- 2〜3社を並べる（「最大3社」なので2社でも可）
- HACCP・監査対応など案件要件に合う実績を優先
- 業者リストは案件ごとに台帳へ記録（次回以降の資産にする）

---

## 5. 再利用メールテンプレート（コピーして使う）

`{ }` を実データに置換。差出人は `info@local-support.jp`（業者向け）/ `support@` or `info@`（依頼者向け）。

### テンプレA：業者への概算見積 打診
```
件名：【ロカサポ】{サービス名}のお見積もりご相談（{エリア}／{案件ID}）

{業者名} 御中

はじめまして。施設管理の一括見積サービス「ロカサポ」運営事務局です。
ご依頼者様よりお預かりした案件について、概算お見積もりのご相談です。

■ 案件概要
・サービス：{サービス名}
・エリア：{都道府県}
・施設：{施設種別}
・管理範囲／規模：{建物全体/2階建/延床◯㎡ 等・未確定なら「未確定（中規模）」}
・希望頻度：{月1回 等}
・要件：{HACCP対応要/記録発行希望 等}

延床面積が未確定のため、下記いずれかでご回答いただけますでしょうか。
(1) 面積帯ごとの「最小〜最大」概算レンジ
(2) 概算が難しい場合は「要現地調査」

あわせて、月額概算（税抜/税込）・初期費用の有無・現地調査の要否と費用をご教示ください。
現段階は「現地調査前の概算」で差し支えございません。

ロカサポ運営事務局（ローカル情報局）
https://local-support.jp/
```

## 6. 比較ページ生成（⑦）の固定手順

1. `cd tools/quote-url && cp template.json my-request.json`（PII含むためコミットしない）
2. `my-request.json` を編集：**全業者で同じ比較項目を埋める**（README のチェックリスト参照。会社名は実名可・連絡先は書かない）
3. `node generate.mjs my-request.json` でURL生成（6,000字以内。会社紹介込みで長い場合はボタン化で対応）
4. テンプレCでURLを依頼者へ送付

---

## 7. クローズ処理（⑩）

- **成約**：業者決定・契約 → 台帳 `成約`、紹介手数料を記録
- **失注**：追わない/連絡不能/依頼者都合中止 → 台帳 `失注` ＋ 理由と学びを記録
- どちらも `leads-log.md` に結果を残し、スプシのステータスも更新

---

## 8. よくある分岐

| 状況 | 対応 |
|---|---|
| メール未取得（電話のみ） | 比較ページのメールフローに乗せられない。電話でメール取得 or 個別対応。※フォームはメール必須化済みなので新規では発生しない |
| 全業者が「要現地調査」 | 比較ページで「無料/有料の現地調査後に正式見積」と正直に表示。テンプレBで各社へ現地調査を依頼 |
| 業者が対応不可・不通 | 別業者を追加打診、または依頼者へ状況連絡。台帳の `見積ステータス` を `辞退`/`不通` に |
| 3社目が来ない | 揃った2社で提示（「最大3社」なので2社でOK） |
