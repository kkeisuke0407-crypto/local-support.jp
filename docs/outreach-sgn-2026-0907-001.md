# SGN-2026-0907-001 追加候補（所沢近郊・看板点検）

2026-09-24 作成。9/7〜9/24 に25社へ打診して紹介可ゼロ・辞退ゼロ（全件無反応）だったため、候補を洗い直した。

## 無反応だった原因の見立て

- 初回の候補は埼玉県の屋外広告業登録簿と川口案件（SGN-2026-0825-001）の流用が中心で、所沢から遠い会社（川口・越谷・春日部・さいたま）が多かった
- 登録簿は「施工の登録」であり、点検を商品にしている会社とは限らない
- 9/7 の打診文に確認項目が5つ（有資格者・報告書・高所作業車・来院者動線など）あり、返信の負担が重かった
- 所沢の地場の看板屋はWebサイトを持たない会社が多く、電話が主な窓口

→ 今回は【点検を商品化している会社】と【所沢市内・隣接市の地場】に絞る。打診文は「紹介可ならその旨だけ返信」の短い型にする。
