# アウトリーチ自動化ツール 仕様メモ

> ステータス：**保留中**（手動メール営業の反応を見てから着手）
> 着手条件：30件手動送信して返信1件以上 → 作る価値あり

## 目的

CSVをアップロードして、Claude APIで1通ごとに個別化したコールド営業を
半自動で送るローカルツール。テンプレ一斉送信（返信率1%）に対し、
個別化で3〜5%を狙う。

## 全体フロー

```
[CSV: 施設名, メアド, サイトURL, フォームURL]
      ↓
[モード選択]
  - AI個別化レベル（下表）
  - 送信方法（メール / フォーム）
  - 承認モード（プレビュー承認 / 自動送信）
      ↓
[Claude が必要な処理を実施]
      ↓
[プレビュー画面で確認 → 承認送信] or [自動送信]
      ↓
[ログ: 送信日時 / 開封（メールのみ） / 返信]
```

## AI個別化モード（コストは Haiku 4.5・150円/$換算）

| モード | 内容 | 費用/通 |
|---|---|---|
| A: AIなし | CSV項目をテンプレ差し込みのみ | 0円 |
| B: 軽量 | 施設名・種別・所在地のみClaudeで1文生成 | 0.1円 |
| C: 標準（推奨） | サイトのmeta+h1を抜粋してClaudeに渡す | 0.3円 |
| D: フル | サイト本文全部をClaudeに渡す | 1円 |

- 最初は B または C で30件 → 効果あれば C/D に上げる
- 30件で約10円、300件で約100円。API費用は無視できる規模。

## 送信方法

### メール（優先実装）
- 経路：Gmail API（1日500件・無料・信頼性高い）
- ウォームアップ：5→10→20→30件/日で段階的に
- From: info@local-support.jp（DKIM/SPF/DMARC設定済み・mail-tester 10/10）

### フォーム営業（後回し・リスク高）
- Playwrightでフォーム自動入力・送信
- ClaudeにフォームHTMLを渡してフィールド特定：1〜3円/件
- reCAPTCHAがあると突破コスト追加（約2円/件）
- **法的・レピュテーションリスク高**：
  - 「営業お断り」フォームに送ると特定電子メール法/民事トラブル判例あり
  - 嫌われやすく初回接点でマイナス
- ユーザー希望で含める。ただしメール営業の反応を見てから判断。

## 承認モード（切替式）
- プレビュー承認：1通ずつ画面で確認・承認後送信（誤爆防止・初期推奨）
- 自動送信：生成→即送信・ログのみ

## 法律メモ（日本・B2B・特定電子メール法）
- 営業メールは原則オプトイン（事前同意）が必要
- **例外：相手が自社サイトで公開しているメアド宛はOK** ← 今回の合法ルート
- 推測メアド・非公開メアドへの送信はNG

## 技術スタック（予定）

- csv-parse（CSV読込）
- Gmail API or nodemailer（送信）
- playwright（フォーム営業・既にdevDependenciesにあり）
