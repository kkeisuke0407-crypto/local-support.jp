## 3. サービスLPのCTRが低い原因＝検索意図のミスマッチ

`/johkasou/` は **120表示・平均4.02位・CTR 0.83%**。4位なら本来CTRは7〜10%あってよい。

流入クエリを見ると原因が分かる。

| クエリ | 表示 | 順位 |
|---|---|---|
| 浄化槽 清掃料金 | 5 | 1.0 |
| 浄化槽清掃費用 | 5 | 1.0 |
| 浄化槽 清掃 費用 | 3 | 1.0 |
| 浄化槽 汲み取り 値段 | 2 | 1.0 |
| 浄化槽清掃代 | 2 | 1.0 |

**すべて「いくらか知りたい」検索**。ところがタイトルは：

```
浄化槽清掃・保守点検の一括見積｜許可業者から最大5社を比較
```

**「見積を依頼する」ページとして名乗っている。** 費用を調べているだけの人はクリックしない。
一方クリックを取れているコラムのタイトルは情報提供型：

```
受水槽清掃の法定義務ガイド｜水道法・建築物衛生法の要点と違反ペナルティ   → 146表示 CTR 2.74%
浄化槽法の保守点検・清掃・法定検査ガイド｜管理者義務と頻度              → 119表示 CTR 2.52%
```

→ **サービスLPのtitle/descriptionを「費用相場を答える」形に寄せる。** descriptionには
既に費用レンジが入っているので、**titleに出すだけ**でよい。表示回数はそのままでクリックが増える、
最も即効性の高い施策。

## 6. CLAUDE.md「横展開は害虫駆除が勝ち筋になってから」の見直し

現行ルールは「害虫駆除が70点以上を3か月続けたら横展開」。しかし実測では

- `/pest-control/` は **19表示・0クリック・10.68位**
- 害虫系コラムのクリックは6か月で **1**

**害虫駆除はGoogleで最も弱いサービスのひとつ。** この条件を満たす日は当分来ない。
一方で害虫駆除では**CVが2件**出ている（Bing・コラム経由）。

→ **「害虫駆除が勝ち筋になるまで待つ」という縛りは実態と合っていない。**
判断軸を「Googleでの順位」ではなく「**CVが出たサービス**」に変えるべき。

## 7. 推奨する運用方針

優先度順。上から着手する。

### ① サービスLPのtitleを費用相場型に変える（即効・低コスト）
417表示・CTR 0.96%。コラム並み（1.92%）で+4クリック、県別LP並み（3.45%）で**+10クリック**。
表示回数を増やさずに済む唯一の施策。まず `/johkasou/`（120表示）から。

### ② コラムを主力と位置づけて継続
表示の66%・クリックの64%。特に**「法令・義務」系が強い**（`*-horei-gimu` が上位を独占）。
`content-backlog.md` の優先順位も、法令・義務 → 費用相場 の順に寄せる。

### ③ 県別LPは増やさない。既存162ページの中身を厚くする
`priceFactor` / `localFactors` の拡充（CLAUDE.mdに既にある方針）。
81ページのインデックス未登録の解消を狙う。**新しい県のnoindex解除はこれが済むまで行わない。**

> ⚠️ **noindexを増やす方向には動かないこと。** 県別LPからは実際にCVが出ている
> （`/jusuisou-seisou/kanagawa/` → WTK-0812、`/furon-tenken/aichi/` → FRN-0824、
> `/pest-control/osaka/` → PCO-0823）。noindexにするとBingからも消え、**CV源を自分で潰す**。

### ④ Bing Webmaster Tools を導入
CVの実体を計測できていない。導入コストは低い。

### ⑤ 404 3件・リダイレクト1件を潰す
軽微だが放置する理由がない。GSCのURL一覧から特定する。

### ⑥ CLAUDE.md の横展開条件を書き換える
「害虫駆除が勝ち筋になってから」→「**CVが出たサービスから**」。
