# ロカサポ 運営ルーチン

ロカサポ（local-support.jp）の運営作業を「毎日／週次／月次」の3段で整理。
**ユーザーの手作業**と **Claude（スケジュール起動）の自動作業**を分離して記述する。

---

## 🌅 毎日

### ユーザーの手作業（合計 5〜15分）

| # | タスク | 目安時間 | 詳細 |
|---|---|---|---|
| 1 | support@local-support.jp メール確認 | 3〜5分 | 新規見積依頼・業者返信・DMARC レポート |
| 2 | フォーム見積依頼の処理（あれば） | 10〜30分 | 該当エリアの業者選定 → 業者比較ページURL発行 → 依頼者にメール |
| 3 | Claude の完了報告を「マージして」で承認 | 1分 | スケジュール起動の `/daily` 結果を main に反映 |

### Claude スケジュール起動（推奨：毎朝9:00）

セッションプロンプト：`/daily`

実行内容:
- 直近24時間のmain変更確認
- backlog から1本コラム執筆（約5,500字）
- ビルド検証
- feature branch へ push
- 完了報告

**1日 1本のみ**（質の担保）。

---

## 📅 週次

### ユーザーの手作業（合計 30〜60分／週）

| # | タスク | 目安頻度 | 詳細 |
|---|---|---|---|
| 1 | 冷メール送信（ランプアップ表に従う） | 週2〜3回 | `cd tools/outreach && npm run send` |
| 2 | Resend ダッシュボードで配信成績確認 | 週1回 | 開封率・バウンス率・スパム苦情率 |
| 3 | GSC 検索パフォーマンス確認 | 週1回 | クエリ・ページ別CTR、新規流入KW |
| 4 | 直近公開コラムの初動チェック | 週1回 | GSC表示・GA4セッション・Clarity滞在時間 |

### Claude スケジュール起動（推奨：週1回・月曜朝）

セッションプロンプト：`/weekly-review`（未実装。後日追加予定）

実行案:
- 直近1週間に公開したコラムのSEO初動分析
- backlog の優先順位再評価
- CODEX とのテーマ被り発見と整理

---

## 🗓 月次

### ユーザーの手作業（合計 1〜2時間／月）

| # | タスク | 目安頻度 | 詳細 |
|---|---|---|---|
| 1 | GSC API 取得 → スコアリングCSV更新 | 月初 | `npm run fetch-gsc`（要 .env 認証情報） |
| 2 | seo-scoring-template.csv の月次採点 | 月初 | `docs/seo-scoring-rules.md` 参照 |
| 3 | 70点以上の「勝ち筋」候補を特定 | 月初 | コンテンツ強化対象として backlog 優先度1に格上げ |
| 4 | 冷メールの数値レビュー | 月末 | 100通あたりCV数を計算、ランプアップ調整 |
| 5 | 業者紹介の運用振り返り | 月末 | 案件成立数・選定業者の傾向・改善点 |

---

## 🚨 イベント駆動（不定期）

### ユーザーの手作業

| # | トリガー | アクション |
|---|---|---|
| 1 | 新規見積依頼が来た | **受注オペは `docs/juchu-operation-sop.md`（標準手順SOP）に一本化。** 起票→業者選定→打診(テンプレA)→見積回収→`tools/quote-url`で比較ページ生成→依頼者へ案内(テンプレC) |
| 2 | 依頼者が業者比較ページで選定 | 選定業者へ連絡先共有(テンプレD)→紹介開始。SOP §5 のテンプレを使用 |
| 3 | 業者から「対応不可」連絡 | 別業者を追加打診、または依頼者に状況連絡 |
| 4 | Cloudflare デプロイ失敗 | ビルドログ確認 → 該当コミットを revert または修正 push |
| 5 | スパム苦情率上昇 | 冷メール一時停止 → 文面・頻度見直し |

### Claude セッション（必要時）

| # | トリガー | コマンド |
|---|---|---|
| 1 | 急ぎでコラム書きたい | `/write-next-column <テーマ>`（引数指定で割り込み実行） |
| 2 | 既存ページの修正必要 | 直接指示 |
| 3 | 新サービス追加 | `src/data/services/` に新規ファイル + 関連設定 |

## 📊 指標ダッシュボード（参考）

定期確認すべき主要KPI:

| 指標 | ソース | 目標 |
|---|---|---|
| GSC 表示回数（直近28日） | Search Console | 月+20% |
| GSC CTR（平均） | Search Console | 3%以上 |
| GA4 オーディエンス（直近30日） | GA4 | 月+30% |
| /audit/ 完了率 | GA4 + イベント | 30%以上 |
| フォーム見積依頼数（月） | inbox + GA4 | 月+1件以上 |
| 業者選定→連絡先共有 → 契約率 | 案件管理 | 50%以上 |
| 冷メール送信数 | tools/outreach/list.csv | ランプアップ計画通り |
| 冷メールバウンス率 | Resend ダッシュボード | 2%以下 |
| 冷メールスパム苦情率 | Resend ダッシュボード | 0.1%以下 |
