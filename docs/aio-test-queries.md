# AI検索引用モニタリング用クエリ集

ChatGPT・Perplexity・Google AI Overview・Claudeに対して定期的に投げ、
local-support.jp が回答ソースに引用されるかを確認するためのテストクエリ集。

## 運用ルール

- **頻度**：週1回（毎週月曜）
- **記録項目**：日付／クエリ／AI／引用有無／引用URL／回答の要約
- **記録先**：`seo-scoring-template.csv` の「AI引用」列に反映
- **判定**：いずれか1AIでも引用されたら、そのページに15点加点

## ベンチマーク

四半期ごとに以下も確認：
- 競合サイトが引用されているか（どのサイトが優位か観察）
- AIごとの引用傾向の違い（Perplexity は被リンク重視、Google AI Overview は構造化データ重視 等）

## 引用率を上げるためのチューニング項目

引用が取れない場合、以下を疑う：
1. **構造化データの不足**：HowTo / AggregateOffer / FAQPage が無いページは弱い
2. **直接回答の遅さ**：本文冒頭で「答え」を言っていない
3. **数値の具体性**：「業者により異なります」より「3〜8万円」のほうが引用されやすい
4. **更新日の古さ**：6ヶ月以上更新がないと AIは古い情報と判断する傾向
5. **被リンク不足**：AI（特に Perplexity）は外部からの言及を重視
