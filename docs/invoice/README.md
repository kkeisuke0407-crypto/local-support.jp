> ⚠️ **住所と振込先は各ファイルの黄色ハイライト部分に直接記入する。**
> このリポジトリは public のため、**確定した住所・口座番号をコミットしないこと。**
> テンプレートにはプレースホルダのみ残す。

## ファイルの種類

| ファイル | 用途 |
|---|---|
| `*.xlsx` | **本命。** Excel で開いて黄色いセルを入力 → PDF出力 |
| `*.html` | ブラウザで開いて入力する版。Excel を使わない場合に |

どちらも中身は同じ。**A4縦1枚**に収まるよう設定済み。

## 使い方

### Excel版（推奨）

黄色いセルは4つだけ。

| セル | 内容 |
|---|---|
| **H10** | 所在地 |
| **C31** | 金融機関（例：◯◯銀行 △△支店） |
| **C32** | 種別・番号（例：普通 1234567） |
| **C33** | 口座名義（例：フジナミ ケイスケ） |

PDFにするには **ファイル → エクスポート → PDF/XPS ドキュメントの作成**
（または 印刷 → プリンター「Microsoft Print to PDF」）。

- 用紙 A4・縦・**1ページに収める**設定済み。倍率はいじらなくてよい
- 行高・列幅を実寸で設計してあり、**縦268.5mm × 横186.9mm**（A4の使用領域 271×185mm）に収まる
- **金額を変えるときは単価（D17）だけ直せば、金額・小計・消費税・合計・上部の請求金額まで自動で再計算される**
- 明細を増やすときは18〜24行目の単価（D列）に入力する。金額（E列）は自動で入り、合計の SUM は E17:E24 を見ている
- シート下部の【記入方法】は印刷範囲の外にあるためPDFには出ない

### HTML版（ブラウザで完結する）

HTMLファイルを**ブラウザで開いて、黄色い部分をクリックするとそのまま入力できる**。
テキストエディタは不要。

1. ファイルをダブルクリック（またはブラウザにドラッグ＆ドロップ）で開く
2. 黄色い4箇所をクリックして入力
   - 所在地／金融機関／種別・番号／口座名義
3. **Ctrl+P（Mac は ⌘+P）→ 送信先を「PDFに保存」** → A4のPDFが出力される
4. メールにPDFを添付して送付

> 💾 **入力内容はブラウザの localStorage に保存される。** 次に別の請求書を作るときも
> 同じ値が自動で入るので、住所と口座を毎回入力する必要はない。
> 保存先はそのブラウザの中だけで、**ファイルにもサーバーにも書き込まれない**。
> このリポジトリは public なので、この仕組みで住所・口座がコミットされるのを防いでいる。
>
> ⚠️ 別のPCやブラウザで開くと空になる。プライベートウィンドウでも保存されない。

画面上部の青い案内文と黄色いハイライトは**印刷時に自動で消える**ので、PDFには入らない。

### 新しい請求書を作るとき

1. 直近のファイルをコピーして案件IDでリネーム
2. 宛名・請求書番号・発行日・品目・金額・支払期限を書き換える
   （HTMLをテキストエディタで開くか、Claude に頼む）
3. 上記の手順でPDF化して送付

## 名義についての注意

サイト上の運営者・著者名は **寺尾 聡**、請求書の発行者は **藤波 圭佑**（事業主）。
業者から見ると別名義に見えるため、**初回の請求時は必ずメール本文で説明する**。

> 「ロカサポ」は屋号「ローカル情報局」として運営しており、事業主は藤波です。
> 請求書は事業主名義で発行いたしますので、藤波の名前で届きます。
> 日頃のご連絡は運営担当の寺尾より差し上げております。

## 再生成

`scripts/make-invoice.py` が生成スクリプト。案件が変わったら以下を書き換えて実行する。

- 宛名・請求書番号・発行日
- 明細（品目・数量・単価）
- 支払期限

```
python3 scripts/make-invoice.py
```

> ⚠️ **openpyxl は数式のキャッシュ値を書かない。** 生成しただけだと Excel 以外のプレビューで
> 金額が空欄に見える。スクリプト実行後、`xl/worksheets/sheet1.xml` の該当セルへ
> `<v>値</v>` を注入している（手順は本セッションの履歴を参照）。Excel で開けば自動再計算される。

> 🚨 **数式の参照先は「ラベルから逆引きして」検証すること。**
> 制作時、上部の「ご請求金額」が合計行ではなく空セルを参照していた（`=E30`／正しくは `=E28`）。
> キャッシュ値を入れると見た目は正しくなるため、**値の一致だけでは検出できない。**
> 「合計」というラベルのある行を探し、参照先がその行かどうかを照合する。
