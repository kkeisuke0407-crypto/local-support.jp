> テンプレートにはプレースホルダのみ残す。

## 使い方

### 住所・振込先の入力（ブラウザ上で完結する）

HTMLファイルを**ブラウザで開いて、黄色い部分をクリックするとそのまま入力できる**。
テキストエディタは不要。

1. ファイルをダブルクリック（またはブラウザにドラッグ＆ドロップ）で開く
2. 黄色い4箇所をクリックして入力
   - 所在地／金融機関／種別・番号／口座名義
3. **Ctrl+P（Mac は ⌘+P）→ 送信先を「PDFに保存」** → A4のPDFが出力される
4. メールにPDFを添付して送付

> 💾 **入力内容はブラウザの localStorage に保存される。** 次に別の請求書を作るときも
> 同じ値が自動で入るので、住所と口座を毎回入力する必要はない。
> 保存先はそのブラウザの中だけで、**ファイルにもサーバーにも書き込まれない**。
> このリポジトリは public なので、この仕組みで住所・口座がコミットされるのを防いでいる。
>
> ⚠️ 別のPCやブラウザで開くと空になる。プライベートウィンドウでも保存されない。

画面上部の青い案内文と黄色いハイライトは**印刷時に自動で消える**ので、PDFには入らない。

### 新しい請求書を作るとき

1. 直近のファイルをコピーして案件IDでリネーム
2. 宛名・請求書番号・発行日・品目・金額・支払期限を書き換える
   （HTMLをテキストエディタで開くか、Claude に頼む）
3. 上記の手順でPDF化して送付

## 名義についての注意

サイト上の運営者・著者名は **寺尾 聡**、請求書の発行者は **藤波 圭佑**（事業主）。
業者から見ると別名義に見えるため、**初回の請求時は必ずメール本文で説明する**。

> 「ロカサポ」は屋号「ローカル情報局」として運営しており、事業主は藤波です。
> 請求書は事業主名義で発行いたしますので、藤波の名前で届きます。
> 日頃のご連絡は運営担当の寺尾より差し上げております。
