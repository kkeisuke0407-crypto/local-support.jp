# 請求書（適格請求書）

紹介料の請求書をここに置く。1案件1ファイル、ファイル名は案件IDに揃える。

## 発行者情報（固定）

| 項目 | 値 |
|---|---|
| 屋号 | ローカル情報局 |
| 事業主 | 藤波 圭佑 |
| **登録番号** | **T2810572974271** |
| 連絡先 | support@local-support.jp |

> ⚠️ **住所と振込先は各ファイルの黄色ハイライト部分に直接記入する。**
> このリポジトリは public のため、**確定した住所・口座番号をコミットしないこと。**
> テンプレートにはプレースホルダのみ残す。

## 使い方

1. 直近のファイルをコピーして案件IDでリネーム
2. 宛名・請求書番号・発行日・品目・金額・支払期限を書き換える
3. ブラウザで開く → 印刷 → **PDFに保存**（A4・余白は既定のまま）
4. メールにPDFを添付して送付

## 名義についての注意

サイト上の運営者・著者名は **寺尾 聡**、請求書の発行者は **藤波 圭佑**（事業主）。
業者から見ると別名義に見えるため、**初回の請求時は必ずメール本文で説明する**。

> 「ロカサポ」は屋号「ローカル情報局」として運営しており、事業主は藤波です。
> 請求書は事業主名義で発行いたしますので、藤波の名前で届きます。
> 日頃のご連絡は運営担当の寺尾より差し上げております。

## 記載事項のチェック（適格請求書の要件）

- [ ] 発行者の氏名または名称
- [ ] **登録番号（T＋13桁）**
- [ ] 取引年月日
- [ ] 取引内容
- [ ] **税率ごとに区分した対価の額および適用税率**
- [ ] **税率ごとに区分した消費税額**
- [ ] 交付を受ける事業者の氏名または名称
- [ ] 振込先口座・支払期限
