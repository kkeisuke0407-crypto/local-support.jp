# hearing-url generator

事前ヒアリングページ（`/hearing/`）のURLを生成するツール。
案件サマリーをURLハッシュに base64 で埋め込むため、サーバー側のストレージは不要。

## 役割（フロー上の位置）

```
[受付（/api/quote）] → [運営が案件確認]
　　　↓
[このツールでヒアリングURL生成] → [依頼者にメール送信]   ← Step 1.5
　　　↓
[依頼者がヒアリングページで詳細回答（面積・階数・エリア・頻度・契約状況等）]
　　　↓
[/api/hearing → 運営に回答メール + 依頼者に確認メール]
　　　↓
[詳細情報が揃った状態で業者選定 → /quote-result/ 発行]
```

## 使い方

```bash
cp sample.json my-case.json
# my-case.json を編集（案件ID・サービス・施設種類・依頼者情報）

node generate.mjs my-case.json
# ローカル確認: node generate.mjs my-case.json --domain=http://localhost:4321
```

出力されたURLを依頼者にメールで送る。回答は運営（contact@local-support.jp）にメールで届く。

## データ仕様

```jsonc
{
  "id": "PCO-2026-0619-001",                  // 案件ID（必須）
  "service": "害虫駆除（業務用PCO）",          // サービス名（必須）
  "facilityType": "食品工場・セントラルキッチン", // 施設種類（作業時間帯の出し分けに使用）
  "prefecture": "福岡県",
  "requester": {
    "name": "海潤貿易株式会社",
    "email": "...@kaijunboeki.co.jp",          // 確認メール送信先
    "tel": "070-xxxx-xxxx"
  }
}
```

## ヒアリングページで聞く項目

### 必須（5問）
1. 延床面積
2. 建物階数
3. 管理したい場所（複数選択）
4. 希望点検頻度
5. 現在の契約状況（→「利用中」なら現在の年間費用を追加表示）

### 条件付き必須
6. 作業可能時間帯（食品工場・スーパー・ホテル・病院・倉庫等の場合のみ表示）

### 任意
- 現在の発生状況
- 衛生監査・HACCP対応の要否
- 築年数
- 自由記入欄（400字）

## 注意

- 施設種類（facilityType）で「作業時間帯」質問の表示が変わる。正確に入れること。
- 依頼者の連絡先はURLに含まれるが、回答が業者に渡るのは選定後（/quote-result/）。
- URL長は 4,000 文字以下が目安。
- このツールは PCO（害虫駆除）専用の質問セット。他サービスへの汎用化は今後の課題。
